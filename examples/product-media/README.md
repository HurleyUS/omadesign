# Current product media

Editable native source projects for the current README, site, and documentation screenshots. Screenshots show the actual compiled Omadesign UI; artwork exports remain separate from app captures.

The canonical mark and wordmark are copied from `assets/omadesign-mark.svg` and `assets/omadesign-wordmark.svg`, without changing their paths or letterforms. The camera photograph is the CC0 Fujifilm X-T30 II sample documented in `site/media-sources.md`; its original stays untouched.

Run `node scripts/refresh-product-media.mjs` with a built `OMADESIGN_BIN` and an isolated display. Outputs, source hashes, and capture receipts belong to `artifacts/media-refresh/`. Project work never writes to `/tmp`.
