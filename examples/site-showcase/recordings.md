# Native recordings

Run `node scripts/refresh-product-media.mjs` using built native tools and an isolated Wayland display. See [the current source guide](../product-media/README.md) and [media provenance](../../site/media-sources.md). Initial documents are seeded; recorded edits use actual egui pointer and key input. Action reports must contain no unresolved targets before publication. Temporary profiles and raw takes stay under the project artifacts directory.
