# 0.6.3-nightly.20261011.0001

Brush packs from [PR #199](https://github.com/michaelmonetized/omadesign/pull/199) enter this Linux nightly through [PR #201](https://github.com/michaelmonetized/omadesign/pull/201). Download the [prerelease](https://github.com/michaelmonetized/omadesign/releases/tag/v0.6.3-nightly.20261011.0001) and the [original CC0 packs](https://omadesign.app/brushes). Stable remains 0.6.3.

Nightlies use `BASE-nightly.YYYYMMDD.NNNN`, with a four-digit daily counter and America/New_York dates. Cargo stores this version as `0.6.3-nightly.20261011.1`; the app, archive names and update downloads use the padded public spelling. Run `node scripts/version.mjs nightly` after fetching tags to prepare the next version and update the nightly website link.

Local qualification passed **1,000 desktop tests**, **35 installer checks**, **21 site tests**, site typecheck and production build. Nine desktop tests are intentionally ignored, including source-dependent fixtures and manual benchmarks. Real source fixtures were qualified separately in the brush-pack receipt. The first desktop run had 999 passes and one five-second Photo save deadline failure during compilation; that check passed independently and the complete two-worker rerun passed in 1,081.77 seconds.

Both architectures build locally and pass the glibc 2.35 and bundled native-library checks. Prefixed installations match their packaged executables. Both paint workspaces and About dialogs rendered through native WGPU; the About captures show the exact public version. Fast captures initially caught the IntelPro modal before its animation settled, so screenshot capture now waits at least one second. Original brush packs roundtrip exactly, and the real six-tip JaxGrass conversion matches across architectures.
