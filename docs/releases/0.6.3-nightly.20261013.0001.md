# Omadesign 0.6.3-nightly.20261013.0001

Published as the latest release. [Download](https://github.com/michaelmonetized/omadesign/releases/tag/v0.6.3-nightly.20261013.0001) or run:

```sh
curl -fsSL https://omadesign.app/install | sh
```

Cargo stores `0.6.3-nightly.20261013.1`; the app, tag, archives and documentation use the padded public version. GitHub marks this selected nightly as a full latest release so the default installer and download buttons resolve it. The October 11 prerelease and 0.6.3 remain available.

## Added

- Square brush, 13 original CC0 tips, and a cursor that follows each tip's outline, pressure-scaled size and angle.
- Spacing up to 10,000%, tip rotation, stroke direction, scatter, and random angle/size/opacity jitter. Portable presets retain these settings.
- Wayland tablet-v2 and X11 pressure input, independent pressure control of Size and Flow, contact ownership and stylus side-button release.
- Current native screenshots and a 40-second product film across the site, README and docs, with the canonical logo and editable source documents.

## Fixed

- Rotated multi-object scaling uses the rotated selection frame. Uniform mixed-angle scaling preserves editable primitives.
- Canvas movement cannot start a sidebar resize; saved sidebar widths persist.
- Dab spacing survives pointer samples and applies consistently to round/sample tips, erasing and masks. Very light pen strokes remain continuous.
- Unrelated touch events cannot finish a mouse or pen stroke; pressure updates and pen cancellation keep contact ownership.
- PDF and animated SVG preserve each contour's closure and curves. Compound paths retain nonzero winding; Simplify retains open endpoints.
- Clone alpha interpolates smoothly; glass highlights respect premultiplied alpha.
- Raster dimension overflow, extreme object IDs, invalid XCF mask tile counts, oversized PDF rasters and PDF image dimensions are validated. Legacy artboard migration allocates unique IDs.
- Photo preset conflicts use the same normalized names as validation. Failed cloud identity saves clean up temporary files.

Fred Nix's contributions from #202, #203 and #204 are integrated through [PR #207](https://github.com/michaelmonetized/omadesign/pull/207).

## Since the October 2 post

Brush library/packs, Photoshop ABR and Illustrator artwork imports, PNG/SVG tips, saved presets, portable exports, OmaStore's official installer entry, archive version checks and stock-file repair all shipped after that post and are included here. Third-party imported packs are not redistributed.

## Qualification

The implementation passed 1,026 library tests (0 failed, 9 ignored), plus separate template-readiness and vendor input regressions. Native media replay captured 4,620 GPU frames with zero unresolved input targets. Release package and public-download receipts are recorded in [the release QA folder](../qa/release-0.6.3-nightly.20261013.0001/).

Builds and tests run locally. Both archives include the ML runtime, licenses, docs, creation skill and starter plugin, with a glibc 2.35 ceiling. The accepted 0.5.0 human-QA evidence is preserved.

Physical tablet acceptance and hotplug remain unverified. Tilt, pad buttons/rings/strips, physical tool rotation and automatic reverse-side eraser switching are not implemented. Native GPU and injected-input checks do not establish physical tablet acceptance.
