# Selected layer merge and stamps

Merge Layers uses selected whole-layer sibling rows in painter order, removes their descendants once, and keeps the top row's identity/name/parent as the merged pixel layer. Unselected rows keep their original data and position relative to the result. Hidden selected rows are discarded by the explicit merge. Pixel Ctrl/Cmd+E chooses this command for multiple rows, Merge Group for one group, and Merge Down for one ordinary layer. A row context menu uses multiple selection only when its actual owner belongs to that selection.

Alt on an existing merge command keeps the reference's stamp meaning. Stamp Visible adds the current visible composite above the active row. Stamp Layers adds a merged copy above the highest selected sibling. Alt-Merge Group adds an isolated group copy. These copies retain the original layers, IDs, masks, styles, native samples and animation. Stamp Down is deliberately different: it replaces the lower pixel layer with the combined pixels while retaining the upper source and its active owner. Locked destination groups/lower pixels refuse; read-only sources can be copied. Pixel Ctrl/Cmd+Alt+E and Ctrl/Cmd+Alt+Shift+E use the existing mode/field shortcut guards. No extra menu rows were introduced.

The existing captured worker, admitted compositor and typed transaction own rendering/cancellation/history. Selection or insertion-owner changes refuse before publication, alongside the existing document/revision/busy checks. A hidden clipping base and its followers stay nonpainting during Visible operations. Normal isolated group stamps preserve masks, opacity and outer effects; Pass Through becoming an isolated copy keeps the same explicit backdrop-dependent boundary as Merge Group.
