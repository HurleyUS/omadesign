# Find Font

Type → Find Font lists authored font usage separately from rendered fallback. Find selects matching text, including hidden and locked stories. Change edits matching selected stories; Change All edits matching writable stories in the document. Both use the existing captured Type target and one history command.

The picker lists real family aliases and OpenType style names from the renderer's system database plus document font bytes. “Closest to original style” uses the source weight and slant. A chosen collection face is extracted to standalone SFNT and registered by content in the existing portable font loader. Opening, picking and cancelling do not edit text. Refresh rescans installed fonts; it never replaces a missing font with a similarly named one automatically.

The initial core has separate exact-source software receipts. Catalog, collection extraction and two native widget routes passed 13 tests at a439f210. The new folder recovery, font refresh and cold-process cases are pending their exact-source group. Native desktop operation and remaining reference parity work stay open. This is not a full Find Font or full product parity completion claim.

Folder discovery checks exact family/style requests, exposes partial results and Stop, and follows the reference time/file/depth boundaries. It skips hidden child directories, links, app packages and system/app data. Explicit Add verifies the search bytes again, preserves name collisions and removes only an operation-owned partial file on failure. Added fonts join the existing renderer database; its SVG layout/paint caches and derived text geometry refresh without a document history step.
