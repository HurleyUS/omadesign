# Imported SVG character metrics

The text properties now report the font size, tracking, cumulative baseline shift, kerning and rendered scale actually used by imported SVG ranges. Reading the inspector does not add overrides or history. Tracking edits convert the native thousandths-of-an-em value using each range's own font size. A requested baseline shift replaces the accumulated source shifts rather than adding to them. Metrics/None kerning choices override a conflicting imported `kern` tag while retaining the other OpenType settings.

The same existing typed command, captured selection and field-history route perform the edits. The native keyboard fixture reaches Tracking and Baseline shift through real Tab input, types the values, verifies visible focus, renders the changes, and checks two separate whole-document Undo steps, full Redo and native/SVG reopen. Mixed 40px/20px text remains mixed in size; tracking 200 becomes 8px/4px. Nested baseline shifts of 10px and 2px can be replaced with zero, positive or negative shifts.

These tests exposed additional renderer/export defects. `textLength` on a parent span was discarded by an intervening child, or repeated independently for styled spans. Within one text chunk, length scopes now share their budget and preserve explicitly sized child glyphs while resolving their reserved advances. Following text and spacing-only adjustment follow the actual resolved positions. A parent containing only explicitly sized children is also covered. Source default black fill and full fill opacity are isolated from the surrounding object wrapper, preventing the first colored/translucent range from recoloring other text during SVG export/reimport.

Native outline-based output requests `text-rendering="geometricPrecision"`; explicitly authored rendering hints remain intact. The regular Chromium comparison runs on the emitted SVG itself. No font-hinting command flag or test-injected precision override is used for the final passing output. The failed default, unhinted and precision-diagnostic runs are retained separately. The [SVG text layout rules](https://www.w3.org/TR/SVG2/text.html) informed the scope handling; actual independent glyph positions and pixels determined the corrections.
