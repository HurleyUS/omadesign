# Variable-font exports

File → Export → SVG has an **Embed fonts** option, remembered with the file and export presets. It keeps real Unicode text and includes each permitted original OpenType program once. Variable coordinates and OpenType features use ordinary CSS settings. Kerning, ligatures, names, license data and variation tables remain in the original font. The source document and font bytes stay unchanged. Import resolves inline fonts through the shared font database and project loader, binds their actual text ranges, and retains them through `.oma` save/reopen.

Native framed and threaded stories now export their actual laid-out visible lines, including object wrap, alignment, clipping and mixed font ranges. Native path text exports a cubic guide and `textPath`, including closed, reversed and wrapped placement. Character scaling, tracking, manual/optical kerning, baseline shift and gradient/pattern ranges use the existing composer positions and paint definitions. Native strokes remain on their original glyph paths. Context-dependent positioning and advanced path details that cannot retain the same glyphs use the existing outlined appearance and report a named reduction; the strict embedded-export API refuses those reductions. The ordinary outline export remains available.

The current QA launcher is `dist/omadesign-text-layouts-qa-118559c6/run`. It opens the wrapped-frame sample. Its `metrics`, `paint`, `frame`, `threads`, `path` and `closed-path` folders contain native workspaces and the corresponding editable SVG. This copy has private preferences and leaves the existing QA application untouched. No public version, release or human acceptance is claimed.

SVG uses standard [CSS font resources and variation settings](https://www.w3.org/TR/css-fonts-4/). Inline standalone TrueType/OpenType faces are limited to 16 MiB each, 64 faces and 64 MiB total. External font URLs are never fetched. Invalid fonts and restricted editable embedding return errors. Only the originally permitted font programs are included.

The shared `usvg` 0.47.0 renderer previously ignored `font-feature-settings`, including small caps. Its local patch now accepts CSS and presentation declarations, inheritance/reset and escaped tags, includes the settings in the existing font/cache identity, and passes them to the same Rustybuzz shaper and fallback faces. Editable SVG imports capture those settings in the existing character style and write accepted native changes back. Actual small-cap changes alter rendered glyphs and survive native reopen and one whole-document Undo/Redo. The original upstream archive, source checksums, copyright and both licenses are retained in `vendor/usvg`; the packaged MIT notice remains complete. Package versions and the 427-component/250-text license inventory are unchanged.
