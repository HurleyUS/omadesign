# Variable-font exports

File → Export → SVG has an **Embed fonts** option, remembered with the file and export presets. It keeps real Unicode text and includes each permitted original OpenType program once. Variable coordinates use ordinary CSS settings; kerning, ligatures, names, license data and variation tables remain in the original font. The native document and source bytes are unchanged. Import resolves inline fonts through the shared font database and project loader, binds their actual text ranges, and retains them through `.oma` save/reopen.

The current QA launcher is `dist/omadesign-svg-fonts-qa-b7052b9b/run`. Its sample contains Regular, ExtraBold and mixed variable ranges. The included `editable.svg` can be opened directly. This copy has private preferences and leaves the existing user QA window untouched. No version, public release or human acceptance is claimed.

SVG uses standard [CSS font resources and variation settings](https://www.w3.org/TR/css-fonts-4/). Inline standalone TrueType/OpenType faces are limited to 16 MiB each, 64 faces and 64 MiB total. External font URLs are never fetched. Invalid fonts and restricted editable embedding return errors. Native framed/path text, manual or optical kerning, scaled characters, automatic hyphenation and non-solid character paints currently require the ordinary outline route. Imported rich SVG text retains its standard positioning and styles. These are explicit remaining limits; full interchange and product parity are open.
