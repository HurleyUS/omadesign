# Layer merges

Pixel Layer and concrete row context menus expose Merge Down, Merge Group, Merge Visible and Flatten Image. Pixel canvas Ctrl/Cmd+E selects Merge Group for a group and Merge Down for an ordinary layer; Shift+Ctrl/Cmd+E selects Merge Visible. The existing mode-aware shortcut dispatcher also supplies key hints. Other modes retain Export on Ctrl/Cmd+E, and focused fields keep native editing ownership.

Merge Down consumes the concrete layer and the sibling immediately below it, retaining the lower layer's identity, name, parent and blend. Merge Group renders a group's contents and masks/effects, retains its identity/name/opacity/blend, and replaces Pass Through with ordinary isolation. Both operations keep off-canvas content. Merge Visible composites visible root trees within the canvas and retains hidden root layers. Flatten Image bakes the current canvas, white background and supported current animation/compositions into a locked Background layer, discarding hidden artwork and baked animation as an explicit destructive operation.

Rendering uses the current byte or authoritative native compositor. The native route preserves HDR/negative RGB samples, alpha, ICC/intent and CMYKA data; it never falls back to preview pixels. Existing native-renderer refusals for effects, SVG paint/graph combinations, live artwork masks and complex unsupported artwork remain refusals. Nonidentity native animation needs the float pose compositor and also refuses. This is not completion of FMT04 or all Motion/native combinations.

Filtered groups retain their off-viewport source pixels until their effects have been drawn. The shared group renderer adds admitted filter padding before clipping to the viewport, so a shadow does not change when a canvas edge crops its source. SVG text at one-to-one scale uses its existing tree/rasterizer on a stable local pixel grid before an integer-position blit. Whole-pixel panning therefore retains glyph coverage; fractional or scaled views keep the existing general path. Pass Through becoming Normal is an explicit group-merge behavior: an isolated group is the exact appearance-preserving case for children whose blends depend on the backdrop.

The existing background-job mechanism owns progress and cancellation. Captured document identity/revision and concrete layer IDs reject stale results before commit. Cancel/Escape retires the result receiver before publication. Accepted output and structural/history changes form one native transaction; Undo restores original layers and editable data. Rendering, allocation, linked-source or validation failure leaves the model/history unchanged.

Baking a live mask must not make its former external source appear as ordinary artwork. An unused remaining mask source is kept nonpainting in the same transaction. A shape mask source inside auto layout currently refuses because hiding it would reflow unrelated artwork. Removing a channel used by an external expression also refuses. These boundaries stay explicit until their complete editable workflows exist.
