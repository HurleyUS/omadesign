# Whole-layer duplication

`Duplicate layer` copies the concrete layer, including its complete nested group, immediately above its source in painter order and within the same parent. The copy becomes the active layer. Pixel mode exposes it in Layer; the Layers copy icon uses it when a layer is explicitly selected, while object selection keeps the existing selection-copy command. A row's context command belongs to that row even when another layer is active.

Preparation is shared with ordinary selection/group duplication. Fresh layer and shape IDs retain frame parents, component definitions, instance baselines, named slots, prototype targets, text stories and live artwork-mask references. Complete text stories keep their internal links; copying only part of a story materializes those copied frames through the existing text helper. Keyframes and expression owners are copied together. Explicit IDs written in expression source retain their original meaning. Native pixels, ICC, CMYKA and masks share immutable allocations until an edit makes its own admitted copy.

An in-place copy preserves stored geometry defaults and raw values. Offset copies use the existing native transform rules. The complete proposed command is checked against hierarchy, mask dependencies, source integrity, component metadata and Motion bounds before one history transaction. Missing/busy or invalid targets and exceeded expression limits preserve the original document, selection and redo stack. Hidden and locked source flags are copied; a read-only copy does not edit its source.

The first exact-source run, `362c3d26`, passed 19 checks and failed two. It exposed raster-default normalization on zero-offset copies and an existing component synchronization omission. At `41db3fe8`, zero-offset copies retain those defaults. Component inheritance now retains local bitmap/live masks, fill opacity, interior blend and text wrapping. Native pixel equality compares authored float bits and color metadata, independently of the rebuildable 8-bit cache. This also distinguishes native masks whose previews happen to match. Component reset still restores the definition. Internal inherited mask references and retained-copy baselines use the existing mask and text remapping routes.

Exact `41db3fe8` passed one coherent group of 42 checks. It covers native HDR/negative-zero/ICC/CMYKA ownership and copy-on-write, masks and parent order, animation owners, complete/partial text-story raster identity, component slots and overrides/reset, same-cache native masks, refusal/redo preservation, and actual top-menu, bottom-icon and row-context keyboard routes. Existing component/property/variant, mask-cache, raster-motion and Actions regressions pass in that group. The original failed receipt remains distinct.

This is same-document duplication. Naming and destination/new-document options, multi-layer destination choices, layer merging/clipping and full Craft product parity remain open. No serialized model fields, reader/schema, resource pool, dependency, application version, installation or public release changes. The human QA window is untouched. The genuine development build and cold CLI sample are recorded separately in `implementation/craft-layer-duplication.json`.
