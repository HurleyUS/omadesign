# Linked document styles

Graphic Styles ▸ Document styles stores named appearances inside the document (project version 39 only when any exist). "Link new style from selection" captures the primary object and links every selected object. Clicking a style applies and links it; Redefine captures the primary object and updates every linked object in one Undo step; Unlink and Delete keep the current artwork. Missing members are dropped on redefine; locked members refuse the whole edit.
