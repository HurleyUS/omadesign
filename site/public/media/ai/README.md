# Editable file workflows

These Fieldwork campaign sources were authored in October 2026 and imported and rendered by the current native Omadesign build. They use Liberation Sans, original vector shapes, and editable text. Poster, square, and wide formats share the same palette and rhythm. Violet variants show a separate revision.

`agent-panel` is an actual native recording of composing a brief beside the design. It stops before sending and contains no staged provider response. The downloaded CLI kit is a separate file workflow.

```sh
omadesign --convert poster.svg --output poster.oma
omadesign --inspect poster.oma
omadesign --convert poster.oma --output poster.png
```

The SVG and OMA sources remain editable. Native import notes and rendered previews must be reviewed before delivery. See the project media manifest for hashes and capture provenance.
